# GenPage: End-to-End Generative Homepage Construction at Netflix

> **Level**: Advanced  
> **Source**: [GenPage: Towards End-to-End Generative Homepage Construction at Netflix](#)  
> **Last Updated**: 2026-08-28

## Introduction

GenPage is an end-to-end generative model developed by Netflix that constructs personalized homepage layouts by autoregressively generating recommendation rows and entities based on user context. This system addresses the complexities of optimizing two-dimensional layouts where content choices are interdependent, replacing traditional multi-stage pipelines with a unified approach. Key applications include dynamically selecting recommendation rows, ranking entities within those rows, and arranging the overall visual interface to enhance content discovery. By conditioning each generation step on prior elements, GenPage enables holistic homepage construction tailored to individual user preferences.

## Core Concepts

### End-to-End Generative Modeling
*   **Shift from Multi-Stage Pipelines:** Traditional homepage construction relies on complex, separate components for candidate generation and ranking at both row and entity levels. GenPage replaces this with a unified approach.
*   **Single Model Architecture:** The system utilizes a single transformer model to handle the entire homepage construction process, moving away from disjointed stages.
*   **Global Optimization:** The goal is to maximize user satisfaction directly by modeling the whole page, rather than optimizing individual lists in isolation.

### Prompt-Response Paradigm
*   **LLM Inspiration:** GenPage adopts the generation style of Large Language Models (LLMs), treating the recommendation task as a natural language problem.
*   **User Context as Prompt:** All known information about the user and the specific request serves as the input "prompt" to the model.
*   **Homepage as Response:** The model answers the implicit question ("Given everything we know... what homepage should we generate?") by producing the full homepage layout as the output.

### Structured 2D Layout Generation
*   **Beyond Flat Lists:** Unlike existing generative recommenders (such as TIGER, HSTU, and OneRec) that generate single ranked lists, GenPage constructs a structured two-dimensional layout.
*   **Row and Entity Integration:** The model generates both the recommendation rows and the specific entities (movies, shows, games) within them simultaneously.
*   **Interdependent Choices:** The system acknowledges that the value of one entity or row affects the others, requiring a model that understands the holistic page structure.

### Autoregressive Construction
*   **Sequential Building:** As illustrated in Figure 1, the homepage is built one row or entity at a time in a specific sequence.
*   **Conditional Generation:** Each new element generated is conditioned on two factors: what has already been placed on the page and the user’s specific context.
*   **Dynamic Influence:** This mechanism ensures that earlier decisions on the homepage influence subsequent choices to maintain coherence and relevance.
