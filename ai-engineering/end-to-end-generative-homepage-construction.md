# End-to-End Generative Homepage Construction

> **Level**: Advanced  
> **Source**: [GenPage: Towards End-to-End Generative Homepage Construction at Netflix](#)  
> **Last Updated**: 2026-08-28

## Introduction

End-to-End Generative Homepage Construction is a machine learning paradigm where a single autoregressive model synthesizes a complete, structured user interface layout based on user context, bypassing traditional multi-stage recommendation pipelines. This methodology addresses the inherent complexity of two-dimensional content organization by optimizing rows and entities collectively rather than in isolation. It is significant for improving content discovery accuracy by directly modeling interdependencies between layout elements, thereby enhancing overall personalization coherence. Primary use cases include streaming service homepages, notably Netflix’s GenPage system, alongside personalized e-commerce landing pages and dynamic news feeds. By generating interface components sequentially conditioned on prior output and specific user data, this approach streamlines engineering architectures while aiming to maximize user engagement through holistic page construction.

## Core Concepts

### Concept 1: End-to-End Single-Model Architecture
*   **Replaces Multi-Stage Pipelines:** Unlike traditional systems that use separate components for candidate generation and ranking at both row and entity levels, GenPage utilizes a single transformer model.
*   **Unified Decision Making:** The model handles the entire construction process simultaneously rather than in fragmented stages.
*   **Efficiency and Constraint:** This approach aims to simplify the system design by constraining the generation process within one cohesive model, moving away from complex, disjointed workflows.

### Concept 2: Structured 2D Layout Generation
*   **Beyond Flat Lists:** While other generative recommenders (e.g., TIGER, HSTU, OneRec) produce flat ranked lists, GenPage generates the full structure of the homepage.
*   **Row and Entity Integration:** The model builds recommendation rows and the specific entities (movies, shows, games) within them together.
*   **Interdependent Value:** It accounts for the fact that layout choices are not independent; selecting a specific row or entity affects the value and perception of other items on the page.

### Concept 3: Autoregressive Prompt-Response Paradigm
*   **Prompt-Response Framework:** The system treats user history and request context as a "prompt" and the generated homepage as the "response."
*   **Step-by-Step Construction:** The homepage is built autoregressively, meaning it generates one row or entity at a time.
*   **Contextual Conditioning:** Each new element is generated based on two factors: the user’s specific context and the content that has already been placed on the page.
*   **Optimization Goal:** The generation is driven by the objective to maximize user satisfaction given the known user data and request constraints.
