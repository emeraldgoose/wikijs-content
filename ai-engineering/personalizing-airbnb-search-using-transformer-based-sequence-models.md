## Introduction

Personalizing Airbnb search using Transformer-based sequence models is a machine learning approach designed to encode longitudinal guest behavior data into dense representations for search ranking. This system addresses the scalability and expressiveness limitations of historical hand-crafted features by modeling complex interaction sequences, such as views and bookings, across multiple sessions and years. By capturing nuanced user preferences rather than relying on aggregated statistics, the model enables precise surfacing of relevant listings. Primary applications include optimizing search result ranking and improving listing relevance through dynamic personalization derived from multi-session user journeys. This methodology facilitates deeper personalization and enhanced relevance compared to static feature sets within large-scale hospitality platforms.

## Core Concepts

### Concept 1: Transition from Static Features to Dynamic Sequence Modeling
*   **Previous Approach:** Search ranking originally relied on hand-crafted features based on aggregated statistics, such as total past bookings or average listing price.
*   **Limitations:** As the number of features grew into the hundreds, the approach became difficult to scale and offered limited expressiveness.
*   **New Approach:** The system now encodes the full guest journey as a sequence, capturing events like views, bookings, reviews, and cancellations accumulated over years rather than flattening them into static stats.

### Concept 2: Leveraging Transformer Architecture for Guest Preferences
*   **Model Choice:** A Transformer-based sequence model is utilized to process guest behavior data.
*   **Representation Learning:** This architecture learns richer representations of guest preferences compared to previous methods.
*   **Outcome:** The system uses these deep behavioral insights to personalize search results, surfacing the right listings at the right time based on the complexity of the guest journey.

### Concept 3: Managing Computational Intractability of Event Sequences
*   **Data Imbalance:** Event sequences per guest are dominated by listing views, which account for the vast majority of all events.
*   **Volume Challenge:** Some guests accumulate hundreds of thousands of views, making raw sequences computationally intractable to model directly.
*   **Signal Complexity:** The model must handle these long sequences while distinguishing meaningful interactions from the overwhelming volume of view data.

### Concept 4: Optimizing for Conversion Rather Than Engagement
*   **Platform Difference:** Unlike social media platforms that typically optimize for user engagement, Airbnb optimizes for booking conversion.
*   **Event Intent:** Bookings are described as rare and deliberate events, whereas listing views may reflect exploration rather than intent.
*   **Model Objective:** The personalization system is designed to identify the signals that lead to conversions despite the rarity of bookings compared to the frequency of views.
