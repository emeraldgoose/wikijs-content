## Introduction

Project-lighthouse-anonymize is an open-source Python library that implements the privacy-preserving anonymization code utilized by Project Lighthouse. Significant for enabling the measurement of potential disparities in user experiences based on perceived race data, the software ensures information is never linked to individual accounts. Primary use cases include executing scalable anonymization algorithms, validating data quality frameworks, and supporting transparency through associated technical papers. The library also facilitates adherence to privacy settings, allowing users to opt out of data usage. Alongside the project's 2020 methodology paper, this release completes the technical narrative regarding implementation and quality validation.
