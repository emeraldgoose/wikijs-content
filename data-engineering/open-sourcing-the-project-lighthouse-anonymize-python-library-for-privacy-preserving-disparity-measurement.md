## Introduction

**project-lighthouse-anonymize** is an open-source Python library developed as part of Project Lighthouse to facilitate privacy-preserving anonymization for disparity measurement. Released alongside three technical papers, the tool enables the analysis of perceived race data without linking it to individual accounts, ensuring user privacy through opt-out settings. This infrastructure matters by allowing the measurement of potential inequalities in user experiences while mitigating privacy risks. Primary use cases include evaluating algorithmic bias across demographic groups, implementing scalable anonymization algorithms, and validating data quality frameworks. The library supports collaboration with civil rights and privacy organizations to audit and mitigate digital disparities transparently.
