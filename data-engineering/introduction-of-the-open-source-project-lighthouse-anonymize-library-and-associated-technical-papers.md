## Introduction

**project-lighthouse-anonymize** is an open-source Python library designed for privacy-preserving data anonymization, released alongside technical papers detailing its scalable algorithms and data quality frameworks. As part of Project Lighthouse, the software enables the measurement of disparities in user experiences without linking perceived demographic data to individual accounts. This release matters because it provides a transparent methodological foundation for ethical analytics, allowing for secure scaling of anonymization processes and independent validation of data quality. Primary use cases include civil rights disparity research, privacy-compliant user experience monitoring, and the implementation of opt-out mechanisms for data collection. Together, the code and accompanying publications establish a complete technical narrative regarding foundational methodology, implementation, and quality verification.

## Core Concepts

### Core Purpose and Privacy Model
Project Lighthouse is designed to measure potential disparities in user experiences (such as those related to perceived race) without compromising individual privacy.
*   **Disparity Measurement:** Enables the analysis of systemic issues in user treatment or content moderation.
*   **No Individual Linkage:** Perceived race data is never linked to specific user accounts.
*   **User Control:** Users can opt-out of data usage via Privacy page settings.
*   **Partnership:** Developed in collaboration with leading civil rights and privacy organizations.

### k-Anonymity Methodology
The foundational technical approach relies on k-anonymity to ensure data cannot be traced back to individuals while retaining analytical value.
*   **Privacy-by-Design:** Established in the original 2020 paper as the core rationale for the project.
*   **Sensitive Attribute Disclosure:** Specifically aims to prevent the exposure of sensitive attributes at scale.
*   **p-Sensitive k-Anonymity:** The methodology incorporates variations of k-anonymity (referenced in blog posts) to enhance protection.

*   **Algorithm Optimization:** Enhances the standard Mondrian approach to suit the specific needs of the project infrastructure.
