# PonderPounce: 사전학습 MLLM을 에피소드 컨텍스트 엔진으로

## 핵심 아이디어
단일 사전학습 MLLM을 **System2 (Ponder) + System1 (Pounce)**로 분해해 로봇 제어에 활용.

## 아키텍처
| | System2 (Ponder) | System1 (Pounce) |
|--|------------------|------------------|
| 입력 | 전체 에피소드 (KV 캐시) | 현재 관측 + 지시 |
| 출력 | 서브골 + 추론 + 인지 토큰 | 액션 |
| 지연시간 | ~78ms p50 | ~25ms p50 (20Hz) |
| 역할 | 숙고, 계획 | 실행, 반응 |

## 인지 토큰
- System2의 최종 레이어 KV 캐시에서 추출
- 에피소드 전체 추론을 압축
- System1에 전달돼 컨텍스트 유지

## 결과
- **단일 모델**로 System2+System1 모두 수행 (별도 모델 불필요)
- 사전학습 지식 보존하며 로봇 제어 적응
- 복잡한 장기 작업에서 베이스라인 대비 큰 향상
