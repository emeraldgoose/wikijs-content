# JIT-Agent: 하네스 지능의 Just-in-Time 진화로 확장

## 핵심 아이디어
에이전트 **하네스(프레임워크)를 태스크별로 동적 합성**해 지능을 확장. 모델 스케일링과 직교하는 접근.

## 4모듈 하네스 프로토콜
1. **메모리 관리**: Working/Episodic/Semantic/Procedural
2. **플래닝 전략**: Plan-and-execute, CoT, ToT, ReAct
3. **액션 프로토콜**: JSON 스키마 검증, 사전/사후 가드
4. **도구 오케스트레이션**: 순차/병렬/조건/루프, 스킬 레지스트리

## JIT 합성 과정
- 태스크 설명 → 하네스 설정 자동 생성
- 벤치마크 기반 모델 선택 (태스크별 파레토 최적)
- 스킬 레지스트리 동적 구성

## 결과
- 고정 하네스 대비 **성능 향상 + 비용 절감**
- 하네스 지능이 모델 크기와 독립적으로 스케일
