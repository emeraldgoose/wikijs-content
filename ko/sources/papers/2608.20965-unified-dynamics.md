# 훈련, 학습, 추론: 통합 역학

## 핵심 아이디어
신경망 훈련, 학습, 추론을 **상태를 가진 파라미터-옵티마이저 시스템의 진화**로 통합 프레임워크에서 설명.

## 주요 통찰
- **훈련 = 시스템 진화**: 파라미터 + 옵티마이저 상태(모멘텀, 분산) = 완전한 상태
- **학습 = 상태 업데이트**: 배치마다 상태 전이
- **추론 = 평형 상태 근처 탐색**: 학습된 분포 주변 샘플링

## 의미
- 옵티마이저 선택 = 역학 시스템 설계
- 학습률 스케줄 = 에너지 랜드스케이프 형성
- 일반화 = 평형 분포의 엔트로피
