# Spotify Engineering — 주요 기사 요약

## 데이터 플랫폼 진화
- **Event Delivery Platform**: 초당 수백만 이벤트 처리, 정확히 한 번 전달
- **Data Mesh**: 도메인 주도 데이터 소유권, 데이터 제품으로 취급
- **Big Data Platform**: Scio (Scala Apache Beam), BigQuery, Dataflow

## 머신러닝 플랫폼
- **Merlin**: 특성 저장소, 모델 레지스트리, A/B 테스트
- **WandB 통합**: 실험 추적, 하이퍼파라미터 튜닝
- **실시간 추론**: TensorFlow Serving, Triton, 커스텀 서빙 레이어

## 오디오/콘텐츠 처리
- **오디오 분석**: Essentia, Librosa 기반 파이프라인
- **자연어 처리**: 다국어 콘텐츠 이해, 팟캐스트 전사/번역
