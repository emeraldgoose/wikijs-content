# Twitter/X Engineering — 주요 기사 요약

## 데이터 인프라
- **Manhattan**: 실시간 분산 데이터베이스, 강한 일관성
- **Gizzard**: 샤딩 프레임워크, 복제/파티셔닝
- **FlockDB**: 그래프 데이터베이스 (소셜 그래프)

## 스트림 처리
- **Heron**: Storm 호환, 백프레셔, 정확히 한 번
- **Sparrow**: 배치→스트리밍 전환 프레임워크

## 머신러닝
- **Cortex**: ML 플랫폼, 특징 저장소, 모델 서빙
- **Ranking**: 다단계 (후보 → 랭킹 → 리랭크), 실시간 특징
