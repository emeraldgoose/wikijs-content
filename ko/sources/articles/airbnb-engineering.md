# Airbnb Engineering — 주요 기사 요약

## 데이터 플랫폼
- **Minerva**: 메트릭 플랫폼, 통합 정의/계산/서빙
- **Chronon**: 특징 엔지니어링 플랫폼, 배치/스트림 통합
- **Airflow**: 워크플로 오케스트레이션 (Airbnb 기원)

## 머신러닝
- **Bighead**: ML 플랫폼, 특징 저장소, 훈련/서빙
- **가격 추천**: 동적 가격 설정 모델
- **검색 랭킹**: 다단계 랭킹 (후보 생성 → 랭킹 → 리랭크)

## 2026년 주요 기사 요약

### Project Lighthouse Part 3: 익명화 라이브러리 오픈소스 공개 (2026-08-25)
- **차등 프라이버시 + k-익명성 + t-근접성**으로 테이블 데이터 익명화
- Spark/Pandas/Polars 연동, ML 학습용 데이터 공유 시 PII 보호

### 팬데믹 이후 모델 재학습: COVID 종료 감지와 언러닝 (2026-08-19)
- 팬데믹 데이터로 학습한 수요 예측 모델이 정상화 시점에 실패
- **연속 재학습 파이프라인** + 드리프트 탐지 + 인간 검증 루프
- **핵심**: 구 체제(팬데믹)의 명시적 음성 예시 필요

### 유연한 인증: 위험 기반 적응형 인증으로 전환 (2026-08-12)
- Passkeys, 디바이스 신뢰도, 행동 생체인식 등 단계적 인증
- 실시간 위험 점수(디바이스/네트워크/행동) → 적응형 챌린지
- 정상 사용자 마찰 감소, 크리덴셜 스터핑 차단

### 평가 주도 개발: GenAI 대규모 평가 체계 (2026-07-28)
- **"평가는 테스트다"**: 자동화, 버전 관리, CI/CD 통합
- 과업별 지표(정확도, 유용성, 안전성) + 비즈니스 지표(전환율, 리텐션)
- 골든 데이터셋, 자동화된 저지자, 인간 평가 풀 구축

### 게스트 여정 학습으로 Airbnb 검색 개인화 (2026-07-21)
- 트랜스포머 기반 시퀀스 모델 (게스트 여정 → 리스팅 점수)
- 검색/클릭/예약/리뷰/메시지 통합 임베딩
- 피처 스토어 연동 실시간 서빙, A/B 테스트로 검증

### LLM 평가 파이프라인: 주 단위 → 일 단위 가속화 (2026-07-14)
- 병목: 인간 평가 지연, 데이터셋 큐레이션, 저지자 캘리브레이션
- 구조화된 루브릭의 LLM-as-judge, 능동 학습으로 인간 샘플링, 병렬 평가 인프라
- 평가 사이클 95% 단축, 모델 반복 속도 대폭 향상

### 멀티 프로덕트 세상을 위한 데이터 아키텍처 진화 (2026-06-09)
- 단일 프로덕트 → 멀티 프로덕트(Experiences, Homes) 데이터 메시 전환
- 도메인 지향 데이터 메시, 자율적 데이터 제품, 중앙 표준(계약/SLA/품질)
- Minerva 메트릭 레이어 + Chronon 피처 플랫폼 + Airflow 오케스트레이션

### Sitar-Agent: 대규모 동적 설정 사이드카 (2026-06-04)
- 설정 드리프트, 느린 롤아웃, 잘못된 설정의 블래스트 레디우스 문제 해결
- 호스트별 에이전트가 설정 서비스 폴링, 로컬 검증, 카나리 + 롤백
- 수백만 설정, 서브초 전파, 99.99% 가용성

### 지리가 역사를 보완한다: 신규 시장 수요 예측 (2026-06-02)
- 신규 시장 콜드스타트 → 지리적 유사성(인구통계, POI, 이동성) 기반 전이 학습
- 시장 유사성 그래프 위 GNN
- 전역 평균 대비 MAE 30% 감소

### 통합 지식 그래프 인프라로 아이덴티티 그래프 확장 (2026-05-19)
- 수십억 에지(유저, 디바이스, 리스팅, 예약, 메시지) 통합 아이덴티티 해결
- Neptune + 커스텀 추론 엔진, Kafka로 실시간 업데이트
- 적용: 사기 탐지, 개인화, 신뢰/안전
