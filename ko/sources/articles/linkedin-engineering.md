# LinkedIn Engineering — 주요 기사 요약

## 데이터 인프라
- **Venice**: 파생 데이터 저장소, 읽기 최적화, 다중 데이터센터
- **Databus**: 변경 데이터 캡처, 실시간 스트리밍
- **Espresso**: 분산 NoSQL, 강한 일관성

## 스트림 처리
- **Apache Samza**: 링크드인 개발, YARN/K8s 네이티브
- **Kafka Streams**: 경량 임베디드 스트림 처리

## 머신러닝
- **Pro-ML**: 특징 저장소, 모델 훈련/서빙 파이프라인
- **GDMI**: 그래프 기반 추천 (지식 그래프 + 임베딩)
